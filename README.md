# Atom Fizikasi - Mobil Ilova (GitHub APK loyihasi)

Ushbu loyiha **Atom fizikasi** fanidan nazariy ma'lumotlar, amaliy masalalar, fizik kalkulyator, interaktiv testlar, 3 ta virtual laboratoriya (Rezerford tajribasi, Bor atomi modeli, Radioaktiv yemirilish) va krossvordni o'z ichiga olgan mobil veb-ilova hisoblanadi. Ilmiy-metodik manba: [tabiiy-fanlar.uz](https://www.tabiiy-fanlar.uz/)

## GitHub orqali APK qilib olish tartibi:

1. GitHub profilingizda yangi **Repository** yarating.
2. Ushbu ZIP arxiv ichidagi barcha fayl va papkalarni (`www/`, `.github/`, `package.json`, `capacitor.config.json`) o'z holicha GitHub repozitoriyangizga yuklang (**Upload files**).
   - **Muhim:** `.github/workflows/build-apk.yml` fayli yashirin papkada bo'lgani uchun yuklanayotganda ko'rinishiga e'tibor bering.
3. Fayllarni saqlab (**Commit changes**) qilganingizdan so'ng, repozitoriyning yuqori menyusidagi **Actions** bo'limiga o'ting.
4. **Build Android APK** jarayoni avtomatik ishga tushadi va 2-3 daqiqada yakunlanadi.
5. Jarayon tugagach, pastki **Artifacts** qismidan **`Atom-Fizikasi-APK`** faylini yuklab oling!
